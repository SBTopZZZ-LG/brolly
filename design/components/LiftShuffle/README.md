Drag-to-reorder for rows: grab by the grip, neighbours shuffle aside, release to settle; Alt+arrows for keyboard.

Add `data-br="sortable"` to the `.br-rows` list or call `Brolly.LiftShuffle.mount(list)`. A `br-reorder` event carries the new order.

- The consumer persists the order.
- Keyboard: focus a row and press Alt+↑ / Alt+↓.
