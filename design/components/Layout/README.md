The bento layout: a 12-column grid of glass tiles with a rail on the left.

`.br-bento` with `.br-tile.br-span-{3,4,6,8,12}`; `Brolly.Layout.tile(inner, span)` builds a tile. Below 900px tiles stack and the rail becomes a bottom bar.

- Tiles hold one thing each: a stat, a list, a chart.
- Use `--space-*` tokens for gaps.
