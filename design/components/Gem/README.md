A small faceted chip for status, tags and counts, with a tone and an optional icon.

`Brolly.Gem.html('Overdue', 'danger', 'alert')` or `<span class="br-gem" data-tone="success">`. Tones: `success`, `warning`, `danger`, `info`, or none for neutral.

- Always include text; the tone is reinforcement only.
- Don't use gems as buttons.
