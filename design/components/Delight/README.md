The finishing touches: time-aware greetings, celebrations, and idle antics.

`Brolly.Delight.greeting(name)` returns a greeting block, `Brolly.celebrate.burst()` fires confetti and an aurora flare, `Brolly.celebrate.done(el, msg)` does it from an element with a toast, and `Brolly.idle.start()` begins the idle sequence (still there? sulking, dimming).

- Celebrate real milestones only (list cleared, goal met), not every save.
- Idle antics are off under reduced motion and wake on any input.
