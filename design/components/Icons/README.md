The hairline icon set: 1.25px stroke, round caps, 24px grid, always currentColor.

`Brolly.icon('plus', 'br-icon--sm')` returns the SVG; `Brolly.iconNames` lists them (about 38). Sizes: `br-icon--sm`, default, `br-icon--lg`.

- Icon-only buttons must have an `aria-label`.
- Don't fill icons or mix in another set.
