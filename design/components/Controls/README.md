Switches, checkboxes, radios and sliders with glass-bead handles that spring when toggled.

Markup classes: `.br-switch`, `.br-check`, `.br-radio`, `.br-slider`; `Brolly.Controls.slider(el)` mounts a slider. Each wraps a native input so forms and keyboards work.

- Always pair with a visible label.
- On/off is shown by bead position and a check or dash, not colour alone.
- Don't build custom toggles from divs.
